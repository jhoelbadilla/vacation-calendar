## Tables

### `users`

Stores authentication identities.

| Column | Type | Constraints | Notes |
| --- | --- | --- | --- |
| `id` | `uuid` | Primary key | Generated by database or app. |
| `username` | `text` | Required | Preserve display casing. |
| `username_normalized` | `text` | Required, unique | Lowercase for login lookup and uniqueness. |
| `email` | `text` | Required | Preserve display casing. |
| `email_normalized` | `text` | Required, unique | Lowercase for login lookup and uniqueness. |
| `password_hash` | `text` | Required | Argon2id or bcrypt hash. |
| `created_at` | `timestamptz` | Required | Creation timestamp. |
| `updated_at` | `timestamptz` | Required | Last update timestamp. |

Recommended constraints:

- `username ~ '^[A-Za-z0-9_-]+$'`.
- `length(username) between 3 and 32`.
- `email_normalized` unique.
- `username_normalized` unique.

### `simulation_profiles`

Stores user-created simulation profiles.

| Column | Type | Constraints | Notes |
| --- | --- | --- | --- |
| `id` | `uuid` | Primary key | Profile identifier. |
| `user_id` | `uuid` | Required, foreign key to `users.id` | Ownership boundary. |
| `name` | `text` | Required | User-visible profile name. |
| `description` | `text` | Nullable | Optional description. |
| `is_archived` | `boolean` | Required, default false | Supports future soft archive. |
| `created_at` | `timestamptz` | Required | Creation timestamp. |
| `updated_at` | `timestamptz` | Required | Last update timestamp. |

Recommended indexes:

- `(user_id, created_at)` for profile lists.
- `(user_id, lower(name))` optionally unique if duplicate profile names should be prevented per user.

### `simulation_settings`

Stores one settings row per simulation profile.

| Column | Type | Constraints | Default | Notes |
| --- | --- | --- | --- | --- |
| `profile_id` | `uuid` | Primary key, foreign key to `simulation_profiles.id` | None | One-to-one profile settings. |
| `current_vacation_hours` | `numeric(8,2)` | Required | `0` | Starting balance. |
| `current_vacation_as_of_date` | `date` | Required | Current date at creation | Effective date for starting balance. |
| `standard_workday_hours` | `numeric(5,2)` | Required | `7.5` | Used for default workdays and day conversion. |
| `vacation_hours_per_work_hour` | `numeric(8,4)` | Required | `0.1` | Accrual rate. |
| `weekends_enabled` | `boolean` | Required | `false` | Controls weekend selection. |
| `created_at` | `timestamptz` | Required | Now | Creation timestamp. |
| `updated_at` | `timestamptz` | Required | Now | Last update timestamp. |

Recommended constraints:

- `current_vacation_hours >= 0`.
- `standard_workday_hours > 0 and standard_workday_hours <= 24`.
- `vacation_hours_per_work_hour >= 0`.

### `day_overrides`

Stores only dates that differ from generated defaults or have explicit notes/settings. Default dates do not need rows.

| Column | Type | Constraints | Default | Notes |
| --- | --- | --- | --- | --- |
| `id` | `uuid` | Primary key | None | Override identifier. |
| `profile_id` | `uuid` | Required, foreign key to `simulation_profiles.id` | None | Parent profile. |
| `calendar_date` | `date` | Required | None | Date being overridden. |
| `work_hours` | `numeric(5,2)` | Nullable | Null | Optional explicit work hours. |
| `vacation_day` | `boolean` | Required | `false` | Vacation toggle. |
| `vacation_hours` | `numeric(5,2)` | Required | `0` | Vacation consumed. |
| `personal_day` | `boolean` | Required | `false` | Personal day toggle. |
| `public_holiday` | `boolean` | Required | `false` | Public holiday toggle. |
| `unpaid_day` | `boolean` | Required | `false` | Unpaid day toggle. |
| `unpaid_hours` | `numeric(5,2)` | Required | `0` | Unpaid hours. |
| `note` | `text` | Nullable | Null | Optional user note for future UX. |
| `created_at` | `timestamptz` | Required | Now | Creation timestamp. |
| `updated_at` | `timestamptz` | Required | Now | Last update timestamp. |

Recommended constraints:

- Unique `(profile_id, calendar_date)`.
- `vacation_hours >= 0 and vacation_hours <= 24`.
- `unpaid_hours >= 0 and unpaid_hours <= 24`.
- `work_hours is null or (work_hours >= 0 and work_hours <= 24)`.

Recommended indexes:

- `(profile_id, calendar_date)` for year-range fetches.
- `(profile_id, calendar_date) where calendar_date >= start and calendar_date <= end` handled by the same B-tree index.

## Generated default day model

The app should generate a complete date model at runtime using profile settings and sparse overrides.

```text
GeneratedDay {
  date: ISODate
  isWeekend: boolean
  isSelectable: boolean
  baseWorkHours: number
  effectiveWorkHours: number
  vacationDay: boolean
  vacationHours: number
  personalDay: boolean
  publicHoliday: boolean
  unpaidDay: boolean
  unpaidHours: number
  accruedVacationHours: number
  runningVacationBalanceHours: number
}
```

## Data ownership rules

- `users.id` is the root ownership key.
- `simulation_profiles.user_id` must match the authenticated user for every protected route.
- `simulation_settings` and `day_overrides` are authorized through their parent profile.
- API responses should not include another user's IDs or profile existence state.
